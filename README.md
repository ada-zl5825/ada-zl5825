## 🔭 Now

- **Research intern @ Microsoft Core AI** — Imperial MSc independent research: an on-device KYC/AML policy copilot. Answers need citations; the last call stays with a human.
- **Recruitment Inbox Agent** — a privacy-first personal agent that turns campus-recruitment mail into reviewable applications, calendar events, and a daily brief. The model extracts; it does not write the database, calendar, or inbox.
